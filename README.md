# Image to PDF Converter (Python Tkinter)

## 📌 Project Overview

Image to PDF Converter is a simple desktop application built using **Python** and **Tkinter**.
It allows users to select multiple images and convert them into a single PDF file.

The application automatically resizes and centers the images so they fit properly on each PDF page.

---

## 🚀 Features

* Select multiple images from your computer
* Supports **PNG, JPG, and JPEG** formats
* Convert images into a single PDF file
* Automatically resizes images to fit the page
* Simple and user-friendly GUI

---

## 🛠️ Technologies Used

* Python
* Tkinter
* Pillow (PIL)
* ReportLab

---

## ▶️ How to Run the Project

Install required libraries:

```
pip install pillow reportlab
```

Run the program:

```
python image_to_pdf.py
```
